## 💡 О проекте

**Developer Portfolio** — персональный сайт-портфолио, представляющий мои навыки, опыт и реализованные проекты.

Сайт создан для презентации себя как junior-разработчика и удобного знакомства с моими работами.

В портфолио представлены:

- Информация обо мне.
- Технические навыки и используемые технологии.
- Реализованные проекты с описаниями и ссылками.
- Этапы работы над заказами.
- Контакты для связи.

Главная особенность проекта — простота адаптации. Информация, оформление и список проектов организованы так, чтобы сайт можно было развивать без использования сложных инструментов и фреймворков.

## 🛠 Технологический стек

| Технология | Назначение |
|---|---|
| **HTML5** | Семантическая структура страниц |
| **CSS3** | Стилизация, анимации, градиенты и glassmorphism |
| **JavaScript ES6+** | Логика интерфейса и динамическое отображение проектов |
| **Google Fonts** | Шрифты Inter и Space Grotesk |
| **IntersectionObserver** | Анимации появления элементов при прокрутке |
| **Clipboard API** | Копирование контактной информации |
| **GitHub Pages** | Бесплатное размещение сайта |

Никаких React, Vue, Tailwind, Bootstrap или jQuery. Только нативные веб-технологии.

```text
│
├── index.html              # Основная HTML-страница
├── style.css               # Стили и адаптивная вёрстка

├── README.md               # Документация проекта
│
└── assets/
    └── images/
        ├── .gitkeep
        ├── avatar.webp
        ├── avatar.png
        ├── project-1.webp
        └── project-2.webp
```

## 🖼️ Изображения и аватар

Для изображений предусмотрена поддержка следующих форматов:

- `.webp`
- `.png`
- `.jpg`
- `.jpeg`

### Аватар

Файлы аватара размещаются в `assets/images/`.

Основной формат — `avatar.webp`.

При отсутствии основного изображения можно использовать PNG или JPG. Если изображение не добавлено, предусмотрен SVG-плейсхолдер с инициалами.

### Изображения проектов

Для каждого проекта можно добавить отдельное изображение.

Например:

```text
assets/images/
├── project-1.webp
├── project-2.webp
└── project-3.webp
```

Путь к изображению задаётся в соответствующем объекте массива `PROJECTS` в `script.js`.

## 🚀 Установка и запуск

Приложение полностью статическое. Сборка и установка npm-зависимостей не требуются.

### 1. Клонирование репозитория

```bash
git clone https://github.com/stepanwillfil-blip/portfolio.git

cd portfolio
```

### 2. Открытие проекта

Открой папку проекта в Visual Studio Code.

### 3. Запуск через Live Server

1. Установи расширение Live Server.
2. Открой `index.html`.
3. Нажми правой кнопкой мыши.
4. Выбери `Open with Live Server`.

Сайт откроется по адресу:

```text
http://127.0.0.1:5500
```

Также можно открыть `index.html` непосредственно в браузере.

## 💼 Работа с проектами

Все проекты хранятся в массиве `PROJECTS` в файле `script.js`.

Для добавления новой работы достаточно создать ещё один объект.

### Структура объекта проекта

```javascript
const PROJECTS = [
    {
        title: "Погодное приложение",
        description: "Показывает текущую погоду и прогноз на 5 дней.",
        stack: [
            "HTML",
            "CSS",
            "JavaScript",
            "OpenWeatherMap"
        ],
        demo: "https://stepanwillfil-blip.github.io/weather-app/",
        github: "https://github.com/stepanwillfil-blip/weather-app",
        image: "assets/images/project-1.webp"
    }
];
```

Карточки проектов формируются JavaScript автоматически на основе данных массива.

**Важно:** структура объекта должна соответствовать логике рендеринга в `script.js`.

## 📱 Адаптивность и доступность

Сайт адаптируется под разные размеры экранов благодаря подходу Mobile First.

Предусмотрены следующие брейкпоинты:

| Ширина экрана | Устройство |
|---|---|
| До 480px | Смартфоны |
| 480–767px | Большие смартфоны |
| 768–1023px | Планшеты |
| От 1024px | Ноутбуки и компьютеры |

Также предусмотрены:

- `alt` для изображений.
- `aria-label` для кнопок-иконок.
- Клавиатурная навигация.
- Стили `focus-visible`.
- Семантические HTML-элементы.
- Метатеги для поисковых систем.
- Open Graph для предпросмотра ссылок.

## 🌍 Публикация на GitHub Pages

Чтобы разместить портфолио в интернете:

1. Создай публичный репозиторий `portfolio`.
2. Загрузи `index.html`, `style.css`, `script.js`, `README.md` и папку `assets/`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** установи:
   - **Source:** `Deploy from a branch`.
   - **Branch:** `main`.
   - **Folder:** `/ (root)`.
5. Нажми **Save**.

После публикации сайт будет доступен по адресу:

**https://stepanwillfil-blip.github.io/portfolio/**

Изменения, отправленные в выбранную ветку, будут публиковаться через GitHub Pages автоматически.
